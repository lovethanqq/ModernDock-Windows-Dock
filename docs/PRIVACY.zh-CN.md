# 隐私说明

简体中文 | [English](PRIVACY.md)

ModernDock 是以本地处理为主的桌面工具。核心功能不需要 ModernDock 账号、云后端、分析服务、广告或遥测服务。

为了完成桌面应用分组和窗口控制，ModernDock 可能读取本机进程/窗口元数据，例如可执行文件路径、进程名、窗口标题、窗口类名和窗口句柄。这些数据只用于本地匹配、显示和控制，开源运行时不会把它们发送到 ModernDock 服务器。

用户配置和 metadata 会保存在当前用户的 ModernDock 安装数据目录中。用户选择的 PNG/ICO 也只保留在本机。公共仓库刻意不包含维护者配置、私人图标目录、原始日志或机器专属运行证据。

ModernDock 运行时可以隐藏 Windows 原生任务栏。正常退出会恢复任务栏；如果强制结束进程导致清理没有执行，公共版提供恢复脚本。
