# Changelog

[简体中文](CHANGELOG.zh-CN.md) | English

## 0.1.1 — Public cleanup release

- Removed maintainer-specific title-based launch behavior.
- Generalized window restore behavior to use real Windows placement state.
- Replaced the public launcher icon special case with generic launcher/host handling.
- No configuration format change.

## 0.1.0 — First public release

- Application-identity based one-app/one-icon grouping
- Path-aware matching for applications with shared executable names
- Bounded self-healing launch paths after application updates
- Drag-to-pin `.exe` / `.lnk` and drag-to-reorder fixed items
- Custom PNG/ICO overrides
- Optical icon normalization based on visible alpha content
- Multi-window lists
- Clock/date area and Core Audio volume flyout
- Generic true-fullscreen-aware auto-hide
- Native taskbar show/hide, single-instance protection and atomic persistence
- Recovery tooling for the native taskbar

This is an early public release. Compatibility coverage will grow through community testing.
